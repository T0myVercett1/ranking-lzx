# 🎭 The Bard's Blind Ranking

莎士比亚戏剧盲选排名游戏 — 一款欧式复古风格的网页小游戏。

## 怎么玩

1. 双击 `index.html` 在浏览器中打开
2. 点击"开始新游戏"
3. 系统会逐一随机放出一部莎士比亚剧目
4. 看到剧目后，立刻选择把它放在 1~10 名的某个空位
5. 一旦选定不可更改，后续剧目只能填入剩余空位
6. 10 部全部排完，生成你的个人喜好排行榜！

## 页面说明

| 页面 | 文件 | 功能 |
|---|---|---|
| 首页 | `index.html` | 规则介绍 + 入口 |
| 后台管理 | `admin.html` | 编辑 10 部剧目池 |
| 游戏页 | `game.html` | 核心盲选排名 |
| 结果页 | `result.html` | 查看排名 + 生成分享图片 |
| 历史 | `history.html` | 查看过往排名记录 |

## 技术栈

- 纯 HTML + CSS + JavaScript
- 零依赖，无需安装任何工具
- 数据存储在浏览器 localStorage
